# Site A — `sites/com.site-a`

The first tenant site and the reference implementation of the `@site/*`
contract: `packages/site-kit` type-checks and tests against it (see
[Multi-site architecture](/architecture/multi-site)).

| | |
| --- | --- |
| Stack | Next.js 16 on `@repo/site-kit` |
| Tenant | `default` (the default tenant; `DEFAULT_TENANT_ID` must match) |
| Local URL | http://localhost:8801 (`bun run dev:site-a`) |
| Deploy | matrix row `site-a`, from the repository root via the root `vercel.json` |

## What this site owns

- `src/site.config.ts` — identity, public pages, agent markdown, and MCP
  toolsets (`content` and `account`).
- `src/app/page.tsx`, `src/app/(marketing)`, `help`, `privacy`, `terms`,
  `changelog` — its public pages.
- `src/components/LandingPage`, `NavBar.tsx`, `Container/PageWrapper.tsx`,
  `magicui` — landing-page and public chrome.
- `content/blog` — its blog posts; `source.config.ts` mirrors `docs-public/`
  (shared pages plus `docs-public/site-a/`).
- `src/app/globals.css` — theme overrides on top of `@repo/react-ui`.

Everything else under `src/app` is a generated shim; change shared routes in
`packages/site-kit/src/app`.
