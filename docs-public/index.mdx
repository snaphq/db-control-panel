# Overview

This repository contains the AlloyDB console and admin portal, plus the
control-plane service that provisions PostgreSQL and libSQL databases. The web
apps use Bun workspaces, Better Auth, PostgreSQL, Drizzle, and shared packages;
the control plane is a separate Hono service with its own database.

Start with [Getting started](/start/getting-started), then configure
[authentication](/configure/authentication) and the
[database](/configure/database). When you are ready to change the code, use
[Project structure](/customize/project-structure).

## What is included

- One current tenant site in `sites/net.alloydb.console`, built from shared
  routes. The workspace and route tooling support adding more sites.
- An admin portal in `apps/backend` for platform administrators.
- A control-plane API and worker in `apps/control-plane` for database
  provisioning, compute operations, libSQL, and the Data API.
- Shared packages for auth, billing, analytics, database, durable execution,
  AI, MCP, and object storage.
- Better Auth with organizations, two-factor auth, passkeys, and an OAuth
  server for MCP clients.
- Optional Stripe, PostHog, Inngest, and agent integrations.
