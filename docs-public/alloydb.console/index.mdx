# Site A

Site A is the first site of this project, built on the shared site-kit routes (sign-in, workspaces, billing, integrations, and an MCP server for agents).

- Local URL: http://localhost:8801 (`bun run dev:alloydb.console`)
- Identity and pages: `sites/net.alloydb.console/src/site.config.ts`
- Brand: `sites/net.alloydb.console/src/app/globals.css`
- MCP: `/mcp` exposes the `content` and `account` toolsets
