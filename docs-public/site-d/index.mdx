# Site D

Site D is a standalone Astro site with its own account dashboard, sharing the database and auth packages but not the Next.js route tree.

- Local URL: http://localhost:8804 (`bun run dev:site-d`)
- Identity: `sites/com.site-d/src/site.config.ts`
