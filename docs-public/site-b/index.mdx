# Site B

Site B is a second site sharing the same platform with its own brand, tenant, and domain.

- Local URL: http://localhost:8802 (`bun run dev:site-b`)
- Identity and pages: `sites/com.site-b/src/site.config.ts`
- Brand: `sites/com.site-b/src/app/globals.css`
- MCP: `/mcp` exposes the `account` toolset
