# Site C

Site C is a standalone SolidStart site: a usage dashboard for its own tenant, sharing the database and auth packages but not the Next.js route tree.

- Local URL: http://localhost:8803 (`bun run dev:site-c`)
- Identity: `sites/com.site-c/src/site.config.ts`
- Requires Node 24
