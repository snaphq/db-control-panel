# Getting started

## Prerequisites

- Bun matching the version in the root `package.json`.
- A PostgreSQL database, for example a free [Neon](https://neon.tech) project.

## Install and configure

```bash
git clone <your-repository-url>
cd <your-repository>
bun install
cp env.example .env.local
```

Fill in at least `DATABASE_URL`, `NEXT_PUBLIC_APP_URL`, `BETTER_AUTH_SECRET`,
and `BETTER_AUTH_URL` in the root `.env.local`. `env.example` lists every
variable; see [Configure authentication](../configure/authentication) for the
auth values. Never commit real values.

## Prepare the database

For local development, push the schema and create the admin user:

```bash
bun run db:push
bun run db:seed
```

Use reviewed migrations (`bun run db:generate` followed by
`bun run db:migrate`) for shared environments.

## Run the app

```bash
bun run dev
```

The Next.js app listens on port `8801` by default. To run only the app without
the Turborepo TUI, use:

```bash
bun run --filter @repo/next-app dev
```
