# Run locally

With dependencies installed and `.env.local` filled in (see
[Getting started](../start/getting-started)), start the full workspace TUI:

```bash
bun run dev
```

Or start one app:

```bash
bun run dev:backend   # admin portal, http://localhost:8800
bun run dev:alloydb.console    # http://localhost:8801
```

Shared secrets live in the root `.env.local`; each web app's local URL lives
in its `.env.development`. The current site runs on port 8801. The control
plane is a separate service and is not started by these commands. The
Databases tab requires `ALLOYDB_API_URL` and `ALLOYDB_API_TOKEN` to point to a
reachable control-plane API. Run the Inngest CLI against the backend
(`http://localhost:8800/api/inngest`) when testing durable jobs.
