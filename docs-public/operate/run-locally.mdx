# Run locally

With dependencies installed and `.env.local` filled in (see
[Getting started](../start/getting-started)), start the full workspace TUI:

```bash
bun run dev
```

Or start only the Next.js app:

```bash
bun run --filter com.site-a dev
```

The app uses port `8801` by default. Run the Inngest CLI separately when
testing durable jobs, and make sure the database and auth variables are set in
the root `.env.local`.
