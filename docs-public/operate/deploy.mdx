# Deploy

## Vercel

Set the selected auth, database, and optional integration variables in the
Vercel project. Use the repository's `vercel.json` build/install settings and
deploy the `sites/com.site-a` output produced by the root build.

Scheduled billing and SEO work is handled through Inngest; configure its
production signing/event values when those jobs are enabled.

## Containers

The repository includes a `Dockerfile`. Provide runtime environment variables
to the container and expose the application port used by the deployment. Run
the same database migration commands separately before serving traffic.

## After deployment

Check `/status`, `/robots.txt`, the OAuth discovery documents, and `/mcp` with
the intended authentication state. Do not use live secrets in smoke-test logs
or documentation examples.
